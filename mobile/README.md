# Mobile app (Android)

App Android cho Smart Room Digital Twin: xem phòng live, biểu đồ, điều khiển cửa sổ/buzzer, và (giai đoạn sau)
điều khiển bằng giọng nói qua LLM. Expo + expo-router + NativeWind, cùng stack với request-app.
